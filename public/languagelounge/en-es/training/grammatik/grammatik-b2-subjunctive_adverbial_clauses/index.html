Subjunctive in Adverbial Clauses (cuando, para que, antes de que)

El subjuntivo en oraciones adverbiales (cuando, para que, antes de que) • B2 • 12 tarjetas

Propósito con 'para que' (+ subjuntivo)

Purpose clauses with 'para que' (so that / in order that)

📌 Nota gramatical

When expressing purpose, 'para que' is always followed by the subjunctive because the action in the dependent clause is only a desired outcome, not a guaranteed reality. Note that if the subject of both clauses is the same, you must use 'para' + infinitive instead of 'para que' + subjunctive.

Ejemplo

Anticipación con 'antes de que' (+ subjuntivo)

Time clauses of anticipation with 'antes de que' (before)

📌 Nota gramatical

'Antes de que' always requires the subjunctive mood because the action it introduces has not happened yet from the perspective of the main clause. Just like with 'para que', if there is only one subject in the sentence, you must drop 'que' and use 'antes de' + infinitive.

Ejemplo

Tiempo futuro con 'cuando' (+ subjuntivo)

Future time reference with 'cuando' (when)

📌 Nota gramatical

When 'cuando' refers to a future event or action relative to the main clause, it triggers the subjunctive. The main clause typically contains a future tense, an imperative, or a present expression of future intent. If 'cuando' refers to a habitual action or a past event, it takes the indicative.

Ejemplo

Concesión con 'aunque' (+ subjuntivo vs. indicativo)

Concession with 'aunque' (even though / although / even if)

📌 Nota gramatical

'Aunque' uses the indicative when stating a known fact ('even though'). It uses the subjunctive when the information is hypothetical, doubtful, or refers to an uncertain future event ('even if'). Master this contrast to express nuanced probability at B2 level.

Ejemplo

Condición con 'a menos que' / 'a no ser que' (+ subjuntivo)

Conditions with 'a menos que' / 'a no ser que' (unless)

📌 Nota gramatical

Phrases meaning 'unless' always introduce a condition that restricts the main clause. Because the condition is hypothetical or potential, these connectors are invariably followed by the subjunctive mood. Note that the infinitive rule does NOT apply here; you keep 'que' and the subjunctive even with one subject.

Ejemplo

Condición con 'con tal de que' (+ subjuntivo)

Condition with 'con tal de que' (provided that / as long as)

📌 Nota gramatical

'Con tal de que' establishes a strict prerequisite for the main clause to take place. It requires the subjunctive mood. Similar to 'para que', if there is only one subject, you shorten it to 'con tal de' + infinitive.

Ejemplo

Modo o manera con 'como' (+ subjuntivo vs. indicativo)

Manner clauses with 'como' (how / the way that)

📌 Nota gramatical

When 'como' indicates a known, factual manner, it takes the indicative. When it expresses a hypothetical manner ('as if' / 'however it may be'), it requires the subjunctive. The subjunctive is typical when referring to an unspecified future method.

Ejemplo

Excepción con 'en caso de que' (+ subjuntivo)

Hypothetical exception with 'en caso de que' (in case)

📌 Nota gramatical

'En caso de que' introduces a contingency or precaution. Because the event is strictly hypothetical or uncertain at the moment of speech, it always triggers the subjunctive. With a single subject, reduce to 'en caso de' + infinitive.

Ejemplo

Tiempo posterior con 'después de que' (Indicativo / Subjuntivo pasado)

Time clauses with 'después de que' (after)

📌 Nota gramatical

Unlike 'antes de que', 'después de que' refers to completed or past actions, so it normally takes the indicative in the past or present. However, when referring to a future event that hasn't happened yet, it requires the present subjunctive. Note: 'después de' + infinitive is used for a single subject.

Ejemplo

Simultaneidad con 'mientras' (+ indicativo vs. subjuntivo)

Simultaneous actions with 'mientras' (while / as long as)

📌 Nota gramatical

'Mientras' takes the indicative when describing actions happening simultaneously as facts. It takes the subjunctive when used conditionally meaning 'as long as' ('mientras que' or 'mientras' meaning 'provided that').

Ejemplo

Límite temporal con 'hasta que' (+ subjuntivo)

Time limits with 'hasta que' (until)

📌 Nota gramatical

Like 'cuando', 'hasta que' takes the subjunctive when referring to a future action or event. When referring to past or habitual events that actually happened, it takes the indicative. Always evaluate whether the endpoint is a reality (indicative) or a future projection (subjunctive).

Ejemplo

Regla del sujeto único: Infinitivo vs. Subjuntivo

Single subject rule: Infinitive instead of subjunctive

📌 Nota gramatical

A fundamental rule in Spanish adverbial clauses (such as para que, antes de que, sin que) is that if the subject of the main clause and the dependent clause is the same person, you must drop 'que' and use a preposition + infinitive. Only when subjects differ do you keep 'que' + subjunctive.
