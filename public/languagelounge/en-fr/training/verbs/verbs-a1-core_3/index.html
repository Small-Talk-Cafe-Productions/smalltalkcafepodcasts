pouvoir

to be able to

📌 Note de grammaire

Third group irregular modal verb, uses avoir.

Exemple

Je peux parler français.

I can speak French.

to want

📌 Note de grammaire

Third group irregular modal verb, uses avoir.

Exemple

Je veux un café.

I want a coffee.

devoir

to have to

📌 Note de grammaire

Third group irregular modal verb, uses avoir.

Exemple

Je dois partir.

I have to leave.

savoir

to know

📌 Note de grammaire

Third group irregular verb, uses avoir.

Exemple

Je sais nager.

I know how to swim.

voir

to see

📌 Note de grammaire

Third group irregular verb, uses avoir.

Exemple

Je vois la maison.

I see the house.

venir

to come

📌 Note de grammaire

Third group irregular verb, uses être in compound tenses.

Exemple

I come from Paris.

partir

to leave

📌 Note de grammaire

Third group -ir verb, uses être.

Exemple

Je pars en vacances.

I am leaving on vacation.

sortir

to go out

📌 Note de grammaire

Third group -ir verb, uses être.

Exemple

📌 Note de grammaire

Exemple

Exemple
