pleuvoir

to rain

📌 Note de grammaire

3rd-person impersonal verb, uses auxiliary avoir, irregular -oir group.

Exemple

Il pleut aujourd'hui.

It rains today.

neiger

to snow

📌 Note de grammaire

3rd-person impersonal verb, uses auxiliary avoir, regular -er group (spelling change e->è in some forms, but mostly used with il).

Exemple

Il neige en hiver.

It snows in winter.

briller

to shine

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

Le soleil brille fort.

The sun shines brightly.

souffler

to blow

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

Le vent souffle fort.

The wind blows hard.

fleurir

to bloom

📌 Note de grammaire

Regular -ir verb (second group), uses auxiliary avoir.

Exemple

Les fleurs fleurissent au printemps.

Flowers bloom in spring.

pousser

to grow / to push

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

L'herbe pousse vite.

The grass grows fast.

tomber

to fall

📌 Note de grammaire

Regular -er verb, uses auxiliary être for motion/state change.

Exemple

Les feuilles tombent en automne.

Leaves fall in autumn.

geler

to freeze

📌 Note de grammaire

Stem-changing -er verb (e -> è), uses auxiliary avoir.

Exemple

Il gèle en hiver.

It freezes in winter.

admirer

to admire

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

J'admire la nature.

I admire nature.

observer

to observe / to watch

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

J'observe les oiseaux.

I observe the birds.

viser

to aim

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

Le soleil chauffe la terre.

planter

to plant

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

Nous plantons un arbre.

We plant a tree.

arroser

to water

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

J'arrose le jardin.

I water the garden.

réchauffer

to warm up

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

Le soleil réchauffe la terre.

The sun warms up the earth.

gronder

to rumble / to scold

📌 Note de grammaire

Regular -er verb, uses auxiliary avoir.

Exemple

Le tonnerre gronde.

The thunder rumbles.

luire

to glow / to shine

📌 Note de grammaire

Irregular -re verb, uses auxiliary avoir.

Exemple

La lune luit dans la nuit.

The moon glows in the night.

cueillir

to pick / to gather

📌 Note de grammaire

Irregular -ir verb (conjugated like -er verbs in present), uses auxiliary avoir.

Exemple

Nous cueillons des fleurs.

We pick flowers.

verdir

to turn green

📌 Note de grammaire

Regular -ir verb (second group), uses auxiliary avoir.

Exemple

Les champs verdissent au printemps.

The fields turn green in spring.

brunir

to turn brown / to tan

📌 Note de grammaire

Regular -ir verb (second group), uses auxiliary avoir.

Exemple

Les feuilles brunissent en automne.

Leaves turn brown in autumn.

couvrir

to cover

📌 Note de grammaire

Irregular -ir verb (conjugated like -er verbs), uses auxiliary avoir.

Exemple

La neige couvre le sol.

Snow covers the ground.
