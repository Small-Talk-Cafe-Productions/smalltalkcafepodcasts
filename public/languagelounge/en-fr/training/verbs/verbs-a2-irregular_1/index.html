aller

to go

📌 Note de grammaire

3rd group, uses auxiliary 'être', completely irregular present tense.

Exemple

Je vais au supermarché ce matin.

I am going to the supermarket this morning.

venir

to come

📌 Note de grammaire

3rd group, uses auxiliary 'être', stem changes in present and future.

Exemple

Tu viens avec nous au cinéma ?

Are you coming with us to the cinema?

vouloir

to want

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', modal verb expressing desire.

Exemple

Je veux un café, s'il vous plaît.

I want a coffee, please.

pouvoir

to be able to (can)

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', modal verb for ability or possibility.

Exemple

Tu peux m'aider avec ces sacs ?

Can you help me with these bags?

devoir

to have to (must)

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', expresses obligation or probability.

Exemple

Je dois partir maintenant.

I must leave now.

savoir

to know (a fact)

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', used for facts and skills.

Exemple

Je sais parler un peu espagnol.

I know how to speak a little Spanish.

prendre

to take

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', drops 'd' in plural present forms.

Exemple

Je prends un café tous les matins.

I take a coffee every morning.

mettre

to put

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', similar conjugation pattern to prendre.

Exemple

Je mets mon manteau, il fait froid.

I am putting on my coat, it's cold.

voir

to see

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', double 'i' in nous/vous imperfect.

Exemple

Je vois un chat dans le jardin.

I see a cat in the garden.

faire

to do / to make

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', highly irregular present and future tenses.

Exemple

Qu'est-ce que tu fais ce soir ?

What are you doing this evening?

dire

to say / to tell

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', note the 'vous dites' irregular form.

Exemple

Je dis la vérité à mes parents.

I tell the truth to my parents.

lire

to read

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', stem adds 's' in singular and plural present.

Exemple

Je lis un roman passionnant.

I am reading an exciting novel.

écrire

to write

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', adds a 'v' in conjugated forms.

Exemple

J'écris une lettre à mon amie.

I am writing a letter to my friend.

boire

to drink

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', stem changes between singular and plural.

Exemple

Je bois de l'eau fraîche.

I am drinking cool water.

sortir

to go out / to leave

📌 Note de grammaire

3rd group, uses auxiliary 'être', drops 't' in singular present forms.

Exemple

Je sors avec mes amis ce soir.

I am going out with my friends tonight.

partir

to leave / to depart

📌 Note de grammaire

3rd group, uses auxiliary 'être', similar conjugation pattern to sortir.

Exemple

Je pars en vacances demain matin.

I am leaving on vacation tomorrow morning.

dormir

to sleep

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', drops 'm' in singular present forms.

Exemple

Je dors huit heures par nuit.

I sleep eight hours a night.

ouvrir

to open

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', conjugated like a 1st group verb in present.

Exemple

J'ouvre la fenêtre pour avoir de l'air.

I am opening the window to get some air.

offrir

to offer / to give (a gift)

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', conjugated like ouvrir.

Exemple

J'offre un cadeau à mon frère.

I am giving a gift to my brother.

courir

to run

📌 Note de grammaire

3rd group, uses auxiliary 'avoir', double 'r' in future and conditional tenses.

Exemple

Je cours dans le parc le matin.

I run in the park in the morning.
