parler

to speak

📌 Note de grammaire

1st group (-er), auxiliary: avoir. Often used with 'à' (to) or 'avec' (with).

Exemple

Je parle français.

I speak French.

dire

to say

📌 Note de grammaire

3rd group, auxiliary: avoir. Irregular 'vous' form: 'dites'.

Exemple

Je dis bonjour.

I say hello.

écouter

to listen

📌 Note de grammaire

1st group (-er), auxiliary: avoir. Direct object (no preposition needed).

Exemple

J'écoute la radio.

I listen to the radio.

écrire

to write

📌 Note de grammaire

3rd group, auxiliary: avoir. Stem changes to 'écriv-' in plural.

Exemple

J'écris un message.

I am writing a message.

lire

to read

📌 Note de grammaire

3rd group, auxiliary: avoir. Stem changes to 'lis-' in plural.

Exemple

Je lis un livre.

I read a book.

répondre

to answer

📌 Note de grammaire

3rd group (-re), auxiliary: avoir. Often used with 'à' (to).

Exemple

Je réponds au téléphone.

I answer the phone.

demander

to ask

📌 Note de grammaire

1st group (-er), auxiliary: avoir. Can mean 'to ask for'.

Exemple

Je demande l'heure.

I ask for the time.

appeler

to call

📌 Note de grammaire

1st group, auxiliary: avoir. Double 'l' before silent 'e' (appelle).

Exemple

J'appelle ma mère.

I call my mother.

expliquer

to explain

📌 Note de grammaire

1st group (-er), auxiliary: avoir.

Exemple

J'explique la leçon.

I explain the lesson.

répéter

to repeat

📌 Note de grammaire

1st group, auxiliary: avoir. Accent changes to 'è' before silent 'e' (répète).

Exemple

Je répète le mot.

I repeat the word.

comprendre

to understand

📌 Note de grammaire

3rd group, auxiliary: avoir. Conjugated like 'prendre'.

Exemple

Je comprends bien.

I understand well.

discuter

to discuss

📌 Note de grammaire

1st group (-er), auxiliary: avoir. Often means 'to chat'.

Exemple

Nous discutons un peu.

We chat a little.

téléphoner

to phone

📌 Note de grammaire

1st group (-er), auxiliary: avoir. Always used with 'à' (to someone).

Exemple

Je téléphone à Paul.

I phone Paul.

envoyer

to send

📌 Note de grammaire

1st group, auxiliary: avoir. 'y' changes to 'i' before silent 'e' (envoie).

Exemple

J'envoie un mail.

I send an email.

raconter

to tell

📌 Note de grammaire

1st group (-er), auxiliary: avoir. Used for stories or events.

Exemple

Je raconte une histoire.

I tell a story.

saluer

to greet

📌 Note de grammaire

1st group (-er), auxiliary: avoir.

Exemple

Je salue mes amis.

I greet my friends.

remercier

to thank

📌 Note de grammaire

1st group (-er), auxiliary: avoir.

Exemple

Je remercie mon ami.

I thank my friend.

s'appeler

to be named

📌 Note de grammaire

1st group, auxiliary: être. Double 'l' before silent 'e' (m'appelle).

Exemple

Je m'appelle Marc.

My name is Marc.

échanger

to exchange

📌 Note de grammaire

1st group, auxiliary: avoir. Keep 'e' in 'nous' form (échangeons).

Exemple

Nous échangeons des idées.

We exchange ideas.

épeler

to spell

📌 Note de grammaire

1st group, auxiliary: avoir. Double 'l' before silent 'e' (épelle).

Exemple

J'épèle mon nom.

I spell my name.
