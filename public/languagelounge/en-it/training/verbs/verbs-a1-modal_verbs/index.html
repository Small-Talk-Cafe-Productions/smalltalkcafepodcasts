potere

to be able to / can

📌 Nota grammaticale

Irregular second-conjugation verb (-ere), uses auxiliary 'avere', modal verb.

Esempio

Posso parlare italiano.

I can speak Italian.

volere

to want

📌 Nota grammaticale

Irregular second-conjugation verb (-ere), uses auxiliary 'avere', modal verb.

Esempio

Voglio un caffè.

I want a coffee.

dovere

to have to / must

📌 Nota grammaticale

Irregular second-conjugation verb (-ere), uses auxiliary 'avere', modal verb.

Esempio

Devo lavorare domani.

I have to work tomorrow.

sapere

to know (how to)

📌 Nota grammaticale

Irregular second-conjugation verb (-ere), uses auxiliary 'avere', often acts semimodally with an infinitive.

Esempio

So nuotare bene.

I know how to swim well.

piacere

to like

📌 Nota grammaticale

Irregular second-conjugation verb (-ere), uses auxiliary 'essere', often used with indirect object pronouns.

Esempio

Mi piace il gelato.

I like ice cream.

to prefer

📌 Nota grammaticale

Esempio

I prefer tea.

Esempio

Esempio
