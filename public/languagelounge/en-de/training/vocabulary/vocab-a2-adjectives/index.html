bequem

comfortable / convenient

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das Sofa ist bequem.') and attributively (e.g., 'ein bequemer Stuhl'). No plural form.

Beispielsatz

Dieses Bett ist sehr bequem.

This bed is very comfortable.

dringend

urgent

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das ist dringend.') and attributively (e.g., 'eine dringende Frage'). No plural form.

Beispielsatz

Ich muss dringend mit dir sprechen.

I urgently need to speak with you.

eng

narrow / tight

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Die Hose ist eng.') and attributively (e.g., 'eine enge Gasse'). No plural form.

Beispielsatz

Diese Schuhe sind mir zu eng.

These shoes are too tight for me.

fett

fatty / greasy

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das Essen ist fett.') and attributively (e.g., 'fettes Fleisch'). No plural form.

Beispielsatz

Dieses Gericht ist mir zu fett.

This dish is too fatty for me.

fleißig

diligent / hardworking

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Sie ist fleißig.') and attributively (e.g., 'ein fleißiger Student'). No plural form.

Beispielsatz

Mein Bruder ist sehr fleißig.

My brother is very diligent.

genau

exact / precise

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das ist genau.') and attributively (e.g., 'die genaue Uhrzeit'). Also often used as an adverb ('genau richtig'). No plural form.

Beispielsatz

Ich brauche die genaue Adresse.

I need the exact address.

komisch

funny / strange

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das ist komisch.') and attributively (e.g., 'eine komische Situation'). No plural form.

Beispielsatz

Das ist aber komisch!

That's strange!

kostenlos

free of charge

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Der Eintritt ist kostenlos.') and attributively (e.g., 'kostenlose Getränke'). No plural form.

Beispielsatz

Die Lieferung ist kostenlos.

The delivery is free of charge.

praktisch

practical / convenient

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das ist praktisch.') and attributively (e.g., 'eine praktische Lösung'). No plural form.

Beispielsatz

Diese Tasche ist sehr praktisch.

This bag is very practical.

typisch

typical

📌 Grammatiknotiz

Can be used predicatively (e.g., 'Das ist typisch.') and attributively (e.g., 'eine typische Situation'). No plural form.

Beispielsatz

Das ist typisch für ihn.

That's typical for him.

nervös

nervous

📌 Grammatiknotiz

Can be used as an adverb. Describes a state of anxiety or agitation.

Beispielsatz

Ich bin vor der Prüfung sehr nervös.

I am very nervous before the exam.

faul

lazy / rotten (food)

📌 Grammatiknotiz

Can be used as an adverb. Has two main meanings: 'lazy' for people/animals, and 'rotten/bad' for food.

Beispielsatz

Sei nicht so faul!

Don't be so lazy!

nützlich

useful

📌 Grammatiknotiz

Can be used as an adverb. Often used with 'für' (for) to specify what it is useful for.

Beispielsatz

Diese Informationen sind sehr nützlich.

This information is very useful.

modern

modern

📌 Grammatiknotiz

Can be used as an adverb. Describes something contemporary or up-to-date.

Beispielsatz

Sie wohnt in einem modernen Haus.

She lives in a modern house.

ganz

whole / entire / complete / quite

📌 Grammatiknotiz

Can be used as an adjective meaning 'whole' or 'complete', or as an adverb meaning 'quite' or 'very'. For objects, it can also mean 'not broken' or 'repaired'.

Beispielsatz

Ich habe den ganzen Kuchen gegessen.

I ate the whole cake.

fest

firm / solid / fixed / tight

📌 Grammatiknotiz

Can be used as an adverb ('firmly', 'tightly'). Describes physical properties or a secure state.

Beispielsatz

Der Knoten ist sehr fest.

The knot is very firm/tight.

weich

soft

📌 Grammatiknotiz

Can be used as an adverb. Describes texture or consistency.

Beispielsatz

Das ist ein weicher Teppich.

That is a soft carpet.

hart

hard / tough / harsh

📌 Grammatiknotiz

Can be used as an adverb ('hard', 'harshly'). Describes texture, difficulty, or severity.

Beispielsatz

Das Brot ist schon hart.

The bread is already hard.

zufrieden

satisfied / content

📌 Grammatiknotiz

Usually used predicatively. Often combined with 'mit' (with) to indicate what one is satisfied about.

Beispielsatz

Ich bin sehr zufrieden mit meiner Arbeit.

I am very satisfied with my work.

böse

angry / evil / naughty

📌 Grammatiknotiz

Can be used as an adverb. Has multiple meanings depending on context: 'angry' (often with 'auf' + Akkusativ for person, 'über' + Akkusativ for thing), 'evil', or 'naughty' (for children).

Beispielsatz

Er ist böse auf seinen Bruder.

He is angry at his brother.

bekannt

known / familiar / famous

📌 Grammatiknotiz

Past participle used as an adjective. Can mean 'known' (to someone, with Dativ) or 'famous' (often with 'für' + Akkusativ or 'als' + Nominativ).

Beispielsatz

Dieser Ort ist mir nicht bekannt.

This place is not known to me.
