# Getting Started with Small Talk Café Podcasts

This guide provides a quick overview of the project and links to detailed documentation.

## Project Overview

Small Talk Café Podcasts is a static website built with:
- **Framework**: Astro 4.16+
- **Styling**: Tailwind CSS 3.4+
- **Language**: TypeScript
- **Node.js**: 18.0.0+
- **Hosting**: GitHub Pages

## 🚀 Quick Start

### Local Development (Fast Track)

```bash
# 1. Navigate to project directory
cd smalltalkcafepodcasts

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Open in browser
# Visit: http://localhost:4321
```

### Deployment (Fast Track)

**Using GitHub Actions (Recommended)**:

1. Update `astro.config.mjs` with your GitHub username
2. Create `.github/workflows/deploy.yml` (see deployment guide)
3. Enable GitHub Pages in repository settings
4. Push to main branch → automatic deployment!

See the [GitHub Pages Deployment Guide](./github-pages-deployment.md) for complete instructions.

## 🔄 Development Workflow

### Making Changes

1. **Start dev server**: `npm run dev`
2. **Edit files**: Make changes in `src/` directory
3. **See changes**: Browser auto-reloads with your changes
4. **Test build**: Run `npm run build` before committing
5. **Preview**: Run `npm run preview` to test production build

### Before Deploying

```bash
# 1. Run type checking
npm run check

# 2. Build for production
npm run build

# 3. Preview the build
npm run preview

# 4. Test at http://localhost:4321/smalltalkcafepodcasts/
```

## 🆘 Common Tasks

### Add a New Podcast Episode

1. Edit podcast data in `src/utils/podcast.ts`
2. Add episode images to `public/images/`
3. Test locally with `npm run dev`
4. Deploy (push to main if using GitHub Actions)

### Modify Styling

1. Edit Tailwind classes in `.astro` components
2. Or modify global styles in `src/styles/global.css`
3. Changes auto-reload in dev mode

### Update Site Configuration

Edit `astro.config.mjs` for:
- Site URL
- Base path
- Build settings

Edit `src/config/site.ts` for:
- Site metadata
- SEO settings

### Add a New Page

1. Create new `.astro` file in `src/pages/`
2. File path = URL path (e.g., `src/pages/about.astro` → `/about`)
3. Use layouts from `src/layouts/`
